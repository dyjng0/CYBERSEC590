# Source provenance

This student adaptation bundles the Dad IT Support Agent application and visual assets from the [Langfuse workshop](https://github.com/langfuse/langfuse-workshop), based on commit `13e067403a8ec8e32904ca84c6cd43224a569d21`, with dual-provider setup fixes and an adapted tracing implementation lesson. The bundled student runtime is untraced.

The entry point was the Duke Gateway Student Pilot supplied for course testing. This is a course adaptation, not an official Ollama, Duke OIT, or Langfuse release. Original names and asset attribution are retained. No additional rights to upstream assets or third-party packages are asserted by this kit.

The archive contains application source and lockfiles; dependencies are downloaded during setup under their respective terms. It excludes Git history, upstream checkpoint tags, installed dependencies, build output, and personal credentials.
